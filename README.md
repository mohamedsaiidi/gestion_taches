# Gestion des tâches (Python, console)

Petite application console pour gérer des tâches quotidiennes.
Projet du module *Outils collaboratifs avec Git / GitHub* (Licence 1, S1).

## Fonctionnalités

- **1 – Ajouter une tâche** : demande un titre (une saisie vide est refusée).
- **2 – Afficher les tâches** : liste numérotée, ou message si la liste est vide.
- **3 – Rechercher une tâche** : affiche les tâches dont le titre contient le mot-clé.
- **0 – Quitter** : ferme le programme ; toute autre option affiche une erreur.

## Étapes réalisées

1. Création du dossier du projet et du fichier `main.py` (menu + ajout + affichage).
2. Ajout de la recherche par mot-clé.
3. Rédaction du `README.md`.
4. Initialisation de Git, commits locaux, puis publication sur GitHub (`git push -u origin main`).
5. Mise à jour après le premier push (amélioration de `main.py`) et second `git push`.

## Exécution

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir `main.py`.
3. Cliquer sur le bouton **Run Python File** (triangle en haut à droite).
4. Utiliser le menu dans le terminal intégré.
